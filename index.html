Komposisi & Bobot Asesmen

Standar penilaian SAS Ganjil

30 Soal Pilihan Ganda (Bobot 60%) L1: 12 • L2: 10 • L3: 8
5 Soal Uraian/Essay (Bobot 40%) L1: 2 • L2: 2 • L3: 1

Rumus Perhitungan Nilai Akhir:

• Nilai PG = (Jumlah Benar / 30) × 100

• Nilai Essay = (Skor Diperoleh / Skor Maksimal) × 100

• Nilai Akhir = (Nilai PG × Bobot PG) + (Nilai Essay × Bobot Essay)

Status Ketuntasan: Ditetapkan Guru: Minimal Nilai 70 (KKTP)

Petunjuk Pelaksanaan Ujian

Tata tertib peserta didik

  1. Klik menu MULAI UJIAN dan isi data identitas dengan benar (Nama Lengkap, NIS/NISN, Kelas, dan Nomor Peserta).
  2. Centang pernyataan pakta integritas kejujuran sebelum memulai ujian.
  3. Ujian dilaksanakan pada tanggal 24 November 2026 dengan waktu pengerjaan 120 menit dan hitung mundur otomatis.
  4. Gunakan navigasi nomor soal: Hijau (terjawab), Kuning (ragu-ragu), Merah (belum dijawab).
  5. Jangan meninggalkan halaman ujian atau berpindah tab karena aktivitas akan tercatat otomatis untuk ditinjau guru.
  6. Untuk soal Essay, tuliskan langkah-langkah penyelesaian secara lengkap pada kotak yang tersedia.

    Panduan Menjalankan Aplikasi Secara Offline

    1. Tanpa Instalasi & Tanpa Internet: Simpan file HTML aplikasi ini ke dalam flashdisk, memori internal HP Android, tablet, atau komputer sekolah. Klik dua kali file tersebut untuk membukanya langsung menggunakan browser (Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari).

    2. Penyimpanan Lokal & Pencadangan: Selama sesi berlangsung, seluruh jawaban peserta tersimpan otomatis di memori perangkat dan penyimpanan lokal browser (IndexedDB). Setelah sesi ujian selesai, guru disarankan mengklik Admin → Backup, Restore & Reset → Unduh File Backup (.json) untuk menyimpan arsip permanen.

    3. Catatan Keamanan Ujian Offline: Aplikasi ini dilengkapi pendeteksi perpindahan tab/jendela layar serta pengacakan urutan soal dan opsi jawaban. Namun perlu dipahami bahwa aplikasi berbasis browser offline tidak dapat mengunci sistem operasi perangkat secara menyeluruh, sehingga pengawasan langsung oleh pengawas ruang tetap diperlukan.
